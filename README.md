Credit & Debit Transaction Analysis

Project Overview

The Credit & Debit Transaction Analysis project focuses on analyzing banking transaction data to understand credit and debit activity, transaction trends, branch and bank performance, transaction methods, and high-risk/suspicious transactions.

The project covers the complete data analytics workflow across Excel, SQL, Power BI, and Tableau.

⸻

Module 1 — Excel

Excel was used for data cleaning, preparation, analysis, and dashboard creation.

Key activities:

* Cleaned and prepared the transaction dataset
* Checked and handled duplicate/missing data
* Analyzed credit and debit transactions
* Created PivotTables and PivotCharts
* Calculated important financial KPIs
* Created an interactive dashboard

Dashboard analysis includes:

* Total Credit Amount
* Total Debit Amount
* Credit-to-Debit Ratio
* Net Transaction Amount
* Account Activity Ratio
* Monthly Transaction Trend
* Branch-wise Transaction Amount
* Bank-wise Transaction Amount
* High-Risk Transaction Flag
* Suspicious Transaction Frequency
* Transaction Method Distribution
* Overall Credit vs Debit
* Monthly Transaction Amount Trend
* Branch analysis

Tools: Microsoft Excel, PivotTables, PivotCharts, Slicers

Module 2 — SQL

SQL was used to perform database-level analysis and answer business questions from the transaction data.

Key activities:

* Queried transaction data
* Analyzed credit and debit amounts
* Used filtering and aggregation
* Compared transaction categories
* Identified high-value/high-risk transactions
* Calculated transaction-level metrics

SQL concepts used:

* SELECT
* WHERE
* GROUP BY
* ORDER BY
* SUM()
* COUNT()
* AVG()
* CASE WHEN

The SQL queries helped extract useful information from the dataset and validate the analysis.
